# IMPERIUM — Sovereign Operating System

An interactive 8-wing strategic codex engineered for executive leverage, pragmatic statecraft, social gravity, cognitive conditioning, and tactical decision drills.

## Live Application
**[Launch IMPERIUM](https://jaykumarshah999-max.github.io/IMPERIUM/)**

## Operational Architecture (8 Wings)
* **01 // Command Center:** Live Self-Command telemetry, Strategic Briefing generator, and wing directory.
* **02 // Realpolitik & Statecraft:** 12 principles of pragmatic realism, second-order consequence mapping, and an interactive 10-Pillar Self-Command Audit.
* **03 // Executive Leverage Matrix:** Domain-indexed strategies across Positioning, Optics & Silence, Alliances, and Timing.
* **04 // Social Gravity:** Outward presence principles, 9 high-gravity archetypes, and a 4-stage connection arc.
* **05 // Cognitive Architecture:** Conscious vs. automatic execution, resolving the Friction Paradox, and alpha-state mental imprinting.
* **06 // Frame & Polarity:** Outcome independence, the Evaluator Stance, Mission-First priority, and calibrated leadership.
* **07 // Tactical Arena:** 3D-flip strategic flashcards and a live scenario simulator with XP tracking.
* **08 // Sovereign War Room:** Browser-persisted strategy journal, saved bookmarks vault, and distilled aphorisms.

## Tech Stack
* Zero-dependency HTML5, CSS3 Custom Properties, and Vanilla JavaScript ES6+
* Progressive Web App (PWA) ready with offline Service Worker caching
* Persistent local state via `localStorage`
